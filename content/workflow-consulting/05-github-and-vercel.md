# Tools: GitHub & Vercel

Beyond the Overview tab's GitHub Basics module, a Process Consultant runs
into two more technical surfaces regularly: reviewing engineering's pull
requests, and understanding what a Vercel deployment actually is when a
client asks why their site looks different in preview versus production.
This is a curated learning path, not a GPC-authored procedure — work through
it once, in order, and come back to it as reference.

| Order | Resource | What to learn | Time |
|---|---|---|---|
| 1 | [GitHub Skills: Introduction to GitHub](https://github.com/skills/introduction-to-github) | Repos, branches, commits, pull requests, merging | ~45–60 min |
| 2 | [GitHub Skills: Review Pull Requests](https://github.com/skills/review-pull-requests) | Reviewing work, commenting, suggesting changes, approvals | ~30 min |
| 3 | [Learn Git Branching](https://learngitbranching.js.org/) | A mental model for branches, commits, HEAD, merge/rebase | ~30–60 min |
| 4 | [Vercel Foundations](https://vercel.com/academy/vercel-foundations) | Deployments, settings, security, logs, observability, rollbacks | ~1 hr |
| 5 | [Vercel Environments](https://vercel.com/docs/deployments/environments) | Local vs. Preview vs. Production, and how git branches create previews | ~20 min |
| 6 | [Vercel Environment Variables](https://vercel.com/docs/environment-variables) | Why a build behaves differently across local, preview, and production | ~20 min |
| 7 | [Vercel Rollbacks](https://vercel.com/docs/deployments/rollback-production-deployment) | What to do when a production deployment breaks | ~15 min |
| 8 | [GitHub Actions: Understanding Actions](https://docs.github.com/en/actions/get-started/understand-github-actions) | Workflows, triggers, jobs, steps — why checks appear on a PR | ~30 min |

If module 1 already covered the basics for you (see the Overview tab), start
at module 2. The GitHub Basics module in Overview and item 1 here teach
overlapping ground on purpose — GitHub Basics is written for someone with
zero prior exposure, while this list assumes you're moving toward reviewing
real engineering PRs and reading a real Vercel deployment.
